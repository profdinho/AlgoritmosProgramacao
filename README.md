# Algoritmos e Programação

Repositório com códigos utilizados como exemplos nas aulas da UC de Algoritmos e Programação da Universidade São Judas, Unidade São Bernardo do Campo.

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

- `src/algoritmosprogramacao/`: Contém a classe principal `AlgoritmosProgramacao.java`.

## Pré-requisitos

- Java Development Kit (JDK) 8 ou superior instalado.
- NetBeans IDE (recomendado para projetos NetBeans).

## Como Executar

1. Clone ou baixe o projeto para o seu computador.
2. Abra o NetBeans IDE.
3. Selecione "File" > "Open Project" e navegue até a pasta do projeto (`AlgoritmosProgramacao`).
4. Abra o projeto no NetBeans.
5. Para executar um exercício específico:
   - Navegue até a classe do exercício desejado (por exemplo, `src/algoritmosprogramacao/desvio/Exercicio01.java`).
   - Clique com o botão direito na classe e selecione "Run File".
6. Alternativamente, para executar o projeto principal:
   - Clique com o botão direito no projeto na aba "Projects" e selecione "Run".

## Compilação Manual

Se preferir compilar manualmente:

1. Abra um terminal na pasta raiz do projeto.
2. Execute o comando: `ant compile` (se o Ant estiver instalado).
3. Para executar: `java -cp build/classes algoritmosprogramacao.AlgoritmosProgramacao`
